### 常见 DPI 下 A4 纸的分辨率对照表

以下是不同场景下 A4 纸对应的像素值：

| DPI | 像素分辨率 (宽 × 高) | 建议用途 |
| :--- | :--- | :--- |
| **72 DPI** | 595 × 842 px | 早期网页/屏幕显示标准 |
| **96 DPI** | 794 × 1123 px | Windows 系统默认显示标准 |
| **150 DPI** | 1240 × 1754 px | 普通文档打印、PDF 预览 |
| **200 DPI** | 1654 × 2339 px | **MinerU/OCR 识别常用分辨率** |
| **300 DPI** | 2480 × 3508 px | 高质量印刷、精细扫描标准 |
| **600 DPI** | 4960 × 7016 px | 专业出版、冲印级别 |
